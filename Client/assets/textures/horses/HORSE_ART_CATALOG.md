# 赛马美术资产权威规范与解剖三视图目录 (Horse Art Catalog)

## 一、资产体系架构

本作共 20 匹纯血赛马，每匹马均拥有规范化、独立无损切分的 8 套标准美术与 3D 资产：

| 资产后缀 | 格式与分辨率 | 描述与用途 |
|---|---|---|
| `_Ortho.png` | RGBA, 1536×960 | **综合解剖三视图 (Turnaround Sheet)**：标准 16:10 古典羊皮纸工程图版，左侧大侧视图 + 右侧正/背立面图，统一鬐甲与地面基准线 |
| `_Ortho_Side.png` | RGBA, 1024×1024 | **正侧剖立面图 (Side Elevation)**：居中高清解剖侧图，展现鬐甲、背线、腹线与飞节角 |
| `_Ortho_Front.png` | RGBA, 1024×1024 | **正前立面图 (Front Elevation)**：居中正视图，展现胸深肌群与正交前肢对称度 |
| `_Ortho_Back.png` | RGBA, 1024×1024 | **正后立面图 (Rear Elevation)**：居中背视图，展现骨盆倾角与后躯半腱肌 |
| `_Showcase.png` | RGBA, 1536×1024 | **古典油画典藏立绘**：19世纪欧洲古典画廊横版艺术油画，用于图鉴与马房大赏 |
| `_Sprite.png` | RGBA, 256px 高 | **透明跑道单帧精灵**：面向右侧，紧凑去白底与边缘抗锯齿 |
| `_Gallop_8f.png` | RGBA, 1024×128 | **8帧四拍极速袭步图集**：按 128×128 切块用于 2D 骨骼与序列帧动画 |
| `_Jockey_8f.png` | RGBA, 1024×128 | **8帧骑师专属彩衣图集**：对应骑师骑乘伏鞍与挥鞭动作 |
