# V1.4.4 管理后台与日志架构

## 服务边界

- `RaceGame.Api`：只面向游戏客户端，保留玩家认证、比赛、投注、钱包、商城、任务、马厩、排行榜、SignalR 与健康检查。
- `RaceGame.Admin`：独立管理后台服务，使用 ASP.NET Core MVC + Razor + Bootstrap 5 + Vue 3 渐进增强；直接复用 Domain / Application / Infrastructure 和 PostgreSQL 数据模型。
- 两个服务不互相引用 Web 项目，避免管理功能泄露到客户端 API。

## 管理后台入口

- HTTPS: `https://localhost:55329/`
- HTTP: `http://localhost:55330/`
- 健康检查: `/health`
- 默认本地管理员由 `003_seed_default_race_rules.sql` 写入 `admin_users`：`admin / RaceGame@2026`。认证使用现有后台管理员表与 PBKDF2-SHA256-100000，不再使用配置文件明文账号。

## 已实现模块

- 仪表盘：玩家、轮次、投注、启用马匹、累计投注等概览。
- 玩家：搜索、启用/禁用。
- 比赛轮次：最近 200 轮查询。
- 投注订单：最近 300 单查询。
- 马匹配置：新增、编辑、启用/停用。
- 比赛规则：修改下注/准备/比赛/赛后间隔、最低下注、初始余额及算法版本。
- 服务日志：直接查看根目录日志最后 500 行。

## 日志目录

项目根目录：

```text
logs/
├─ api/
│  └─ api-YYYYMMDD.log
└─ admin/
   └─ admin-YYYYMMDD.log
```

记录框架日志、HTTP 请求摘要、业务日志和异常堆栈。不记录密码、JWT、Refresh Token 或请求正文。

## 数据库

继续使用 PostgreSQL `postgres` 数据库；不自动创建数据库、不自动 Migration。仍按：

1. `001_initial.sql`
2. `002_upgrade_existing_schema.sql`
3. `003_seed_default_race_rules.sql`

执行。
