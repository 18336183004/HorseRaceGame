# V1.3 修复与验收说明

## 已修复
1. Docker PostgreSQL 与 API 原配置的数据库名/账号密码不一致。
2. SQL migration 与 EF `Database.Migrate()` 不一致：Docker 首次建库直接按 001→002→003 执行。
3. Worker 增加 Redis 轮次推进锁，避免多实例重复创建/推进。
4. 有下注轮次按本轮开始时间至少 300 秒后创建下一轮，补足“约5分钟周期”。
5. 无下注轮次按产品规则跳过比赛并立即进入下一轮。
6. Cocos 客户端增加 JWT、服务端时间同步、下注接口、轮次轮询和阶段倒计时。
7. 增加玩家摘要、下注历史、钱包、钱包流水、我的轮次下注、赛果、服务器时间 API。
8. 比赛未完成前不向客户端暴露动画和最终赛果。
9. 页面与资源使用统一 Placeholder 节点结构预留。
