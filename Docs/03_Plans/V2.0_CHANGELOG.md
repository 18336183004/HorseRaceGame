# V2.0.0 变更记录

## 文档

- 新增产品圣经、V2.0 需求、架构、数据、API、发布、QA、原型映射和实施计划。
- 更新项目规范与 Cocos 场景结构。

## 服务端

- 登录失败 5 次锁定 10 分钟。
- 新增 Refresh Token Logout。
- 下注/商城增加请求参数 SHA-256 指纹，拒绝同幂等键不同参数重放。
- 新增 `/api/race/history`。
- 历史固定管理员账号由 006 禁用，生产/开发后台管理员改为环境变量 bootstrap。
- 生产配置去除数据库/Redis/JWT 固定密码。

## 客户端

- 大厅近期赛果改为服务端历史数据。
- 新增钱包账单页。
- 删除现金/链上充值、USDT、虚假转赠/邀请入口。
- 删除不存在的第二货币展示。
- 客户端版本统一为 2.0.0。
- Logout 使用服务端会话撤销。

## 部署

- 新增完整 PostgreSQL + Redis + API/Worker + Admin Compose。
- 新增 `Database/DeployInit` 生产初始化快照，排除测试玩家和固定管理员。
- 新增 Dockerfile 与 `.env.example`。

## 验证

- TypeScript `npm run typecheck`：PASS。
- `Tools/verify_v2.py`：PASS。
- 当前执行环境无 .NET SDK、Docker、PostgreSQL，因此没有虚报 .NET/数据库/Docker 验证结果。
