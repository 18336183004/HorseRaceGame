## 1. 欧美 18-20 世纪历史写实马匹解剖学基准

在二次创作转化为 Cocos 2D 骨骼与精灵时，必须严格遵守英国画家与解剖学家 George Stubbs（1724–1806）以及 19 世纪欧洲纯血马（Thoroughbred）与温血马繁育图版的经典生物力学结构：

```text
               (头部 Head: 1.0 标准基准单位)
               ┌──────────┐
               │   Head   │── Ears (双耳灵活前探/后贴)
               └────┬─────┘
                    │ (颈项 Neck: 长度约 1.2~1.3 个头长，弓形自然凸出)
               ┌────┴─────┐
               │ Cervical │── Withers (鬐甲/肩隆: 全身骨骼最高点之一)
               └────┬─────┘
        ┌───────────┴────────────────────────┐
        │                                    │
  (前躯 Forehand: 45°~50°斜肩)           (中躯 Trunk / Back: 短紧平直，腰部丰满)
 ┌──────┴──────┐                       ┌─────┴──────┐
 │  Scapula    │                       │  Thorax &  │
 │ (肩胛骨)   │                       │  Abdomen   │
 └──────┬──────┘                       └─────┬──────┘
 ┌──────┴──────┐                             │ (后躯 Hindquarters: 动力发动机)
 │   Humerus   │                       ┌─────┴──────┐
 │  (肱骨)     │                       │   Pelvis   │── Croup (臀骨最高点)
 └──────┬──────┘                       │  (骨盆骨)  │
 ┌──────┴──────┐                       └─────┬──────┘
 │   Radius    │ (前臂长，前膝平正)     ┌─────┴──────┐
 │  (桡骨/前臂)│                       │   Femur    │ (股骨粗壮)
 └──────┬──────┘                       │  (股骨/大腿│
 ┌──────┴──────┐                       └─────┬──────┘
 │ Knee(Carpus)│ (腕关节/膝)           ┌─────┴──────┐
 └──────┬──────┘                       │    Tibia   │ (胫骨)
 ┌──────┴──────┐                       └─────┬──────┘
 │ Cannon Bone │ (管骨短而致密)        ┌─────┴──────┐
 │  (掌骨/管骨)│                       │ Hock Joint │ (飞节: 角度约 150°~160°)
 └──────┬──────┘                       └─────┬──────┘
 ┌──────┴──────┐                       ┌─────┴──────┐
 │ Fetlock/Past│ (球节与系部: 弹性缓冲) │ Cannon Bone│ (后管骨垂直地面)
 └──────┬──────┘                       └─────┬──────┘
 ┌──────┴──────┐                       ┌─────┴──────┐
 │    Hoof     │ (蹄呈45°自然着地)      │ Fetlock/Hoo│ (后蹄比前蹄稍尖长)
 └─────────────┘                       └────────────┘
```

### 比例校准核心数据：
1. **肩高基准**：肩隆（Withers）高度等于 **2.4 个头长**。
2. **体长基准**：肩端（Point of shoulder）至臀端（Point of buttock）的水平长度约为肩高的 **1.05 倍**（呈现黄金长方形体态）。
3. **肢长与躯干比例**：肩隆到肘部深度，约等于肘部到地面的距离（1:1 等高平衡）。

## 3. Cocos 2D 骨骼绑定体系与 28+ 拆件层级拓扑树

在 Cocos Creator 中使用 2D Spine 或 DragonBones 时，建议以**侧面视图 (SIDE)** 为主骨骼架构，建立如下骨骼拓扑结构（按父子关系排布）：

```text
root (基底位置，X/Y 地面投影)
 └─ hip_center (重心骨，控制整马上下沉浮与核心推力)
     ├─ spine_lumbar (腰椎)
     │   └─ thorax_chest (胸廓与鬐甲)
     │       ├─ neck_1_base (颈部根部)
     │       │   └─ neck_2_mid (颈部中部)
     │       │       └─ neck_3_upper (颈部上段)
     │       │           ├─ head (头部核心)
     │       │           │   ├─ ear_near / ear_far (近侧/远侧双耳，表达情绪)
     │       │           │   ├─ jaw (下颌骨，张嘴嘶鸣/咀嚼)
     │       │           │   └─ nostril (鼻孔微扩贴片)
     │       │           └─ mane_1, mane_2, mane_3 (鬃毛三段柔体摆动)
     │       ├─ shoulder_near (近侧前肩胛骨)
     │       │   └─ leg_F_near_upper (近侧前臂)
     │       │       └─ leg_F_near_lower (近侧前管骨)
     │       │           └─ pastern_F_near (前球节系部)
     │       │               └─ hoof_F_near (前蹄)
     │       └─ shoulder_far (远侧前肩胛骨 - Z-Order 置于胸腔后方)
     │           └─ leg_F_far_upper ─ leg_F_far_lower ─ pastern_F_far ─ hoof_F_far
     ├─ pelvis (骨盆)
     │   ├─ leg_B_near_thigh (近侧后大腿/股骨)
     │   │   └─ leg_B_near_hock (近侧飞节/胫骨)
     │   │       └─ leg_B_near_cannon (近侧后管骨)
     │   │           └─ pastern_B_near (后球节)
     │   │               └─ hoof_B_near (后蹄)
     │   ├─ leg_B_far_thigh (远侧后大腿 - Z-Order 垫底)
     │   │   └─ leg_B_far_hock ─ leg_B_far_cannon ─ pastern_B_far ─ hoof_B_far
     │   └─ tail_base (尾骨基底)
     │       └─ tail_mid (尾骨中段)
     │           └─ tail_tip (尾毛梢端，柔体物理链)
```

### 渲染图层（Draw Order / Z-Order）深度规范：
1. `Far Legs & Hooves`（远侧四肢与蹄）：Z = -20
2. `Far Ear & Far Shoulder`（远侧耳与肩）：Z = -10
3. `Torso & Abdomen`（主躯干与腹腔）：Z = 0
4. `Neck & Head & Jaw`（颈项、头、下颌）：Z = 10
5. `Mane & Tail`（鬃毛与尾巴）：Z = 15
6. `Near Legs & Hooves`（近侧四肢与蹄）：Z = 20
7. `Near Ear & Tack/Saddle`（近侧耳、马鞍与辔头）：Z = 30

## 4. 四大类 35 项动画逐项技术拆解与关键帧曲线

### 一、步态与移动类（8项）

| 序号 | 动作名称 | 英文 | 生物力学足序与节奏 (Footfall) | 动画周期 (Duration) | Cocos 关键帧曲线与运动学重点 |
| :---: | :--- | :--- | :--- | :---: | :--- |
| **01** | **慢步 / 走** | **Walk** | **四拍依次 (4-beat)**：<br>1.左后(LH) → 2.左前(LF) → 3.右后(RH) → 4.右前(RF)<br>地面始终保持 2~3 蹄着地。 | 1.0s (60帧)<br>循环 Loop | `hip_center` 呈现平缓双波峰垂直正弦位移（±8px），头部随每一单前肢下落而轻微下沉（点头缓冲，落差约 12px）。 |
| **02** | **快步 / 小跑** | **Trot** | **两拍对角 (2-beat)**：<br>1.LH + RF 同时落地 → 悬空期 (Suspension) → 2.RH + LF 同时落地 → 悬空期。 | 0.65s (39帧)<br>循环 Loop | 躯干有极为明显的垂直弹性反弹，鬐甲与臀部同频升降。飞节（Hock）强力弯折驱动，鬃尾具滞后半拍的摆动反力。 |
| **03** | **跑步 / 慢跑** | **Canter** | **三拍不对称 (3-beat)**：<br>（以左领先为例）：1.RH → 2.LH+RF → 3.LF(领先前肢) → 短暂悬空。 | 0.52s (31帧)<br>循环 Loop | 重心呈现明显的“前后俯仰式波浪摆动”，后躯深踏下沉，前躯随后扬起。领先腿（Lead leg）步幅明显加大 25%。 |
| **04** | **袭步 / 疾驰** | **Gallop** | **四拍最速爆发 (4-beat)**：<br>1.外侧后肢 → 2.内侧后肢 → 3.外侧前肢 → 4.内侧前肢(冲刺领先) → **完全腾空期**。 | 0.40s (24帧)<br>循环 Loop | 身体极度延展折叠：空中收缩阶段四蹄完全聚拢于腹下，延展阶段前肢向前无限探伸、后肢向后全力蹬平。颈部如长矛般平直前冲。 |
| **05** | **后退** | **Back** | **对角两拍逆序**：<br>LH+RF 离地向后挪移 → RH+LF 离地后撤。 | 0.85s (51帧)<br>循环 Loop | 重心后移压低骨盆，头颈微收，下颌内收紧贴胸口。四蹄离地极低，拖曳后移。 |
| **06** | **转弯** | **Turn** | 内侧肢体作为轴心制动，外侧肢体划出较大弧线推力；头颈先转向。 | 0.75s (45帧)<br>过渡 Once | 头颈骨骼朝转向方向旋转 15°~25°，躯干 Spine 产生横向弧形倾斜（Roll 5°~8°），外侧腿步幅加大。 |
| **07** | **侧步** | **Sidepass** | 侧向横移：双前肢与双后肢交替产生前后交叉交叉步（Leg-yield）。 | 0.90s (54帧)<br>循环 Loop | 躯干与前进方向保持 90° 垂直，肢体无前后位移，仅有横向位移与膝肘部的向外展开。 |
| **08** | **急停** | **Sliding stop** | 双后肢瞬间向下深踏深陷（Hocks low），双前肢小步快速踩踏减震。 | 0.80s (48帧)<br>单次 Once | 骨盆下沉 35px，后管骨与地面几乎平行滑行；颈部抬高以转移后坐力，尘土骨骼特效配合触发。 |

### 二、日常与生理类（11项）

| 序号 | 动作名称 | 英文 | 状态与姿态表现 | 动画时间 | Cocos 骨骼关键节点参数 |

| **09** | **站立** | **Stand** | 自然待机（Idle）：四蹄着地，单后肢交替微屈歇蹄（Cocked hoof）。 | 2.5s 循环 | `thorax_chest` 呼吸轻微缩放（ScaleY 1.0~1.03），双耳微转，尾巴慢速小幅摆动。 |

| **13** | **饮水** | **Drink** | 颈项下伸至水面，喉部肌肉与食道产生吞咽蠕动。 | 1.8s 循环 | 头部平稳不动，颈下缘皮肤贴片微幅上下伸缩波浪传导。 |
| **14** | **伸懒腰** | **Stretch** | 前双肢大幅向前探伸，胸廓下压接近地面，后躯高耸拉伸脊椎。 | 1.4s 单次 | 前肘部着地，脊椎 `spine` 呈明显凹弧形下弯，颈前伸，尾根挺直。 |
| **15** | **蹭痒** | **Rub/Scratch** | 面部或臀部侧向蹭碰木桩、栏杆，双眼微眯。 | 1.2s 循环 | 头部或臀骨作左右 ±15px 的高频摩擦摆动，耳后仰。 |

| **17** | **抖身** | **Shake** | 全身皮肤与鬃毛由前向后高频抖动（从鼻尖一直抖动到尾尖）。 | 0.9s 单次 | 头部首先左右狂甩，紧接着胸骨、腹部、臀部依次传递 12Hz 极微幅高频振动。 |
| **18** | **喷鼻** | **Snort** | 鼻翼鼓胀，气流急速喷出，头微微上昂后急促下顿。 | 0.6s 单次 | `head` 上昂 10° 后瞬间下砸 15°，鼻孔贴片缩放放大 1.3 倍后收缩。 |
| **19** | **排尿/排粪**| **Urinate** | 后肢稍微向外展宽站立，尾根高高抬起翘出。 | 2.0s 单次 | `tail_base` 向上弯折 40°，骨盆微拱，后肢承重外扩。 |

## 6. Cocos Creator 动画状态机 (FSM) 与 CrossFade 融合过渡表

在 Cocos Creator 3.8.8 中挂载 Spine 组件时，为了防止状态切换突变导致闪烁穿模，必须在 `AnimationStateData` 中设置科学的平滑过渡时间：

```typescript
// Cocos Creator 3.8.8 赛马状态机混合配置示例
import { _decorator, Component, sp } from 'cc';
const { ccclass, property } = _decorator;

@ccclass('HorseAnimationFSM')
export class HorseAnimationFSM extends Component {
    @property(sp.Skeleton)
    skeleton: sp.Skeleton = null!;

    onLoad() {
        const stateData = this.skeleton.getStateData();
        
        // 1. 步态平滑加速过渡
        stateData.setMix('Walk', 'Trot', 0.25);
        stateData.setMix('Trot', 'Canter', 0.20);
        stateData.setMix('Canter', 'Gallop', 0.18);
        
        // 2. 减速与急停
        stateData.setMix('Gallop', 'SlidingStop', 0.12); // 急停必须快速响应
        stateData.setMix('SlidingStop', 'Stand', 0.30);
        stateData.setMix('Gallop', 'Canter', 0.22);
        stateData.setMix('Canter', 'Trot', 0.25);
        stateData.setMix('Trot', 'Walk', 0.30);
        stateData.setMix('Walk', 'Stand', 0.35);

        // 3. 突发状态与起扬
        stateData.setMix('Stand', 'Rear', 0.15);
        stateData.setMix('Stand', 'Buck', 0.15);
        stateData.setMix('Gallop', 'Jump', 0.10); // 起跳瞬间帧
        stateData.setMix('Jump', 'Gallop', 0.15); // 落地回衔接
    }
}
```
