## 三、20 匹小马驹与 4 阶段成长生理演化规范

小马驹的成长模拟必须严谨遵循马匹生理发育学。20 匹小马驹（`FOAL_01` 至 `FOAL_20`）在养成系统中分别经历以下 4 个时期：

### 4 大成长发育阶段对比与解剖学规律

```text
[幼驹期 Foal] ────────> [青年期 Yearling] ────────> [成年期 Adult] ────────> [职业赛马 Racing Pro]
(0~6 个月)               (1~2 岁)                 (3~4 岁)                (4 岁以上竞技期)
· 腿长身短(长腿比例85%)  · 臀高肩低(发育不平衡)    · 肩臀齐平(比例成熟)     · 肌肉拉丝/体脂<8%
· 腹部圆鼓、绒毛未褪      · 骨架伸长、肌肉初显      · 胸阔背实、骨骺闭合     · 佩戴赛马鞍辔/护腿绷带
· 眼神好奇、依赖母马      · 精力充沛、爱刨地跳跃    · 沉稳威仪、步履稳健     · 竞技压迫感、目光锐利
```

1. **幼驹期 (Foal, 0~6 个月)**
   - **比例**：头大身小，颈短而弱。最显著特征是**前肢与后肢长度已达到成年马的 80%~85%**，使得小马站立时显得特别高挑摇晃。
   - **皮毛**：绒毛丰厚松软，鬃尾未成形，尾巴似毛刷。
   - **三视图拆块特征**：关节肿大（幼年骨骺未闭合），无明显肌肉分块，线条圆润。

2. **青年期 (Yearling / Colt / Filly, 1~2 岁)**
   - **比例**：处于“尴尬生长期”（Awkward Stage），**臀高往往比肩鬐高出 2~5 厘米**，呈现前低后高的倾斜感。
   - **皮毛**：褪去幼毛，换出具有成年特征的光泽短毛，鬃毛自然垂落。
   - **三视图拆块特征**：骨架迅速拉大，各关节开始收紧，胸腹开始形成马甲线，四肢肌肉束初显。

3. **成年期 (Adult, 3~4 岁)**
   - **比例**：体态达黄金比例（以体长与体高基本相等的方形结构）。肩鬐与臀部平衡，颈脊弧度饱满。
   - **皮毛**：毛色深邃饱满，鬃毛浓密顺滑。
   - **三视图拆块特征**：完整的成年纯血骨架，胸肌、臀肌、肩胛肌饱满分块，是 2D 切件的标准参考体。

4. **职业赛马期 (Racing Pro, 4 岁+ 竞技巅峰)**
   - **比例与体态**：极低体脂率，皮下腹壁浅静脉（Vena saphena）隐约凸显，四肢筋腱如钢缆收紧。
   - **装备装束**：佩戴纯手工超轻赛马皮笼头、鞍部号码布（1~6号）、防石子竞技眼罩（Blinkers）及专业前肢防护马靴/绷带（Polo wraps）。
   - **三视图拆块特征**：增加装具图层（Saddle, Bridle, Wraps），便于 Cocos 骨骼挂件（Attachment / Slot）动态更换装扮。

## 四、四大类 30+ 项动作 Cocos 2D 骨骼切件与动画状态机规范

### 1. 2D 骨骼层级架构（Spine / DragonBones 节点树）

为在 Cocos 中实现逼真的 2D 动画，建议将侧视图（Side View）按以下层级切图：

```text
root (地面原点 / 投射阴影)
└── bone_pelvis (骨盆中心，主控制骨)
    ├── bone_torso (躯干胸腔)
    │   ├── bone_neck_1 (颈根)
    │   │   └── bone_neck_2 (颈中)
    │   │       └── bone_head (马头)
    │   │           ├── bone_jaw (下颌/嘴唇，用于嘶鸣、吃草、龇牙)
    │   │           ├── bone_ears (双耳，用于直立前倾、后贴威吓)
    │   │           └── slot_mane (颈鬃 1~3 节物理摆动)
    │   ├── bone_front_leg_L (前近景腿：肩胛 -> 臂骨 -> 前膝 -> 球节 -> 蹄)
    │   └── bone_front_leg_R (前远景腿：同上，层级在躯干下方，色调暗15%)
    ├── bone_back_leg_L (后近景腿：大腿骨 -> 飞节 -> 跖骨 -> 球节 -> 后蹄)
    ├── bone_back_leg_R (后远景腿：同上，层级在骨盆下方，色调暗15%)
    └── bone_tail_1 (马尾基部)
        ├── bone_tail_2
        └── bone_tail_3 (末端柔体摆动)
```

## 六、Cocos Creator 二次创作切件与集成指引

### 1. 图像切块与导出流程
1. 打开 Photoshop 或 GIMP，载入对应马匹的 `_Ortho.jpg`（三视图）。
2. 在侧视图上按骨骼图层建立选区：
   - 躯干 `torso.png`
   - 头颈 `head.png`, `neck.png`, `jaw.png`, `ear.png`
   - 腿部 `leg_fl_upper.png`, `leg_fl_lower.png`, `hoof_fl.png` 等各关节
   - 尾部 `tail_1.png` ~ `tail_3.png`
3. 导出透明通道 PNG，并将各切片锚点（Pivot）设在关节旋转中心（如肩关节中心、膝眼中心、飞节拐角）。
4. 导入 Spine 或 Cocos 2D Animation 组件进行动画曲线（Easing）调节。

### 2. 运行时动作调用代码示例 (TypeScript)

```typescript
import { _decorator, Component, sp } from 'cc';
const { ccclass, property } = _decorator;

@ccclass('HorseAnimationController')
export class HorseAnimationController extends Component {
    @property(sp.Skeleton)
    public skeleton: sp.Skeleton = null!;

    // 播放指定状态动画
    public playHorseAction(actionName: string, loop: boolean = true) {
        if (!this.skeleton) return;
        this.skeleton.setAnimation(0, actionName, loop);
    }

    // 赛马比赛加速/冲刺状态平滑过渡
    public transitionToSprint() {
        // 先进入加速，0.2秒后混入全力冲刺
        this.skeleton.setAnimation(0, 'ACT_35_Accelerate', false);
        this.skeleton.addAnimation(0, 'ACT_36_Sprint', true, 0.2);
    }
}
```
