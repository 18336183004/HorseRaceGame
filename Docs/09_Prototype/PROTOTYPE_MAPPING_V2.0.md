# 上传原型融合说明 V2.0

上传长图作为视觉/业务参考，不以低清小字号文字作为精确数值来源。

| 原型区域 | V2.0 落地 |
|---|---|
| 角色立绘/展示 | 大厅 + 角色页 |
| 6 马比赛画面 | Race 页面 + 服务端动画 |
| 马匹列表/统计 | 马场 |
| 玩家/马匹排名 | 排行榜 |
| 任务/奖励 | 每日任务 |
| 商城/道具 | 金币商城 |
| 注单/记录 | 注单 + 钱包账单 |
| 系统弹窗 | 统一错误/结果/公告提示 |
| QR/充值/链上视觉 | 不作为 V2.0 功能，避免虚假能力 |

## UI 原则

1. 720×1280 竖屏优先；
2. 顶部 HUD + 中央主内容 + 底部 5 Tab；
3. 核心动作只保留真实可用按钮；
4. 下注按钮必须显示选马、金额、赔率、预计净奖励；
5. 比赛期间禁止修改下注；
6. 结果页明确显示“本轮是否跳过、中奖金额、手续费、净奖励”。
