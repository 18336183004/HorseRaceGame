# 《西部边境赛马会》马匹图鉴立绘生成提示词
# 全局规范（每张图都必须遵守）
1. 风格：欧美 18-20 世纪古典纯血马写实图鉴插画，羊皮纸影棚白底，无背景景物，无骑手。
2. 透视：纯平视侧面（Side）/ 正对马头（Front）/ 正对马臀（Back），无透视畸变。
3. 解剖：严格马科解剖比例，四蹄完整落地，头部朝向画面右方（侧面图）。
4. 用色：写实油润被毛光泽，鬃尾丝质感，马蹄高光，禁止卡通、禁止 Q 版、禁止水印文字。
5. 输出：单匹成年马全身像，透明或纯白背景，居中，四周留白 10%。

## 小马：荒野微风 / Wild Breeze (F01, 荒原混血 Wild Cross)
- 性别：雄马  毛色：骝毛 (Bay)

### 需要生成的 4 张图（同一匹小马的四个生长阶段，纯左侧面）

- 阶段：幼驹期 Foal（约 0~1 岁）→ 保存为 `F01_WildBreeze_Stage1_Foal.png`
  体态：腿长占成年85%，头大身短，腹部圆鼓，绒毛丰厚蓬松，骨骺未闭合，线条圆润可爱。

- 阶段：青年期 Yearling（约 1~2 岁）→ 保存为 `F01_WildBreeze_Stage2_Yearling.png`
  体态：尴尬发育期。臀高比肩鬐高 2~5cm，骨架纵向拉伸，褪去胎毛换出光泽短毛，步态轻快富有弹跳力。

- 阶段：成年期 Adult（约 3~5 岁）→ 保存为 `F01_WildBreeze_Stage3_Adult.png`
  体态：成熟黄金比例。肩鬐与臀部齐平，胸廓宽深，骨骼完全闭合，胸肌臀肌分块饱满。

- 阶段：职业赛马 Racehorse（约 5 岁以上）→ 保存为 `F01_WildBreeze_Stage4_Pro.png`
  体态：体脂低于8%，肌肉紧绷拉丝，皮下腹壁静脉隐现。佩戴专业竞技超轻马鞍、号码布与护腿绑带。
