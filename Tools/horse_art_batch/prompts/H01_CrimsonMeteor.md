# 《西部边境赛马会》马匹图鉴立绘生成提示词
# 全局规范（每张图都必须遵守）
1. 风格：游戏级写实图鉴插画（18-20 世纪欧洲纯血马解剖图鉴的造型准确度 + 当代角色概念图的完成度），纯白影棚底，无背景景物，无骑手。
2. 透视：纯平视侧面（Side）/ 正对马头（Front）/ 正对马臀（Back），无透视畸变。
3. 解剖：严格纯血赛马解剖比例，冲刺型体态——鬐甲高、胸深窄、后躯饱满、四肢修长清瘦；四蹄完整落地，侧面图头部朝右。
4. 用色与质感：油润赤栗被毛高光、丝质鬃尾、马蹄抛光高光；毛色与鬃尾身份必须跨视图一致；禁止卡通、禁止 Q 版、禁止水印文字。
5. 输出：单匹成年马全身像，纯白背景，居中，四周留白约 10%。
6. 禁止：多马、九宫格、正/侧/背拼图、中文标注、图表、水印、风景、骑手。

## 马匹：赤焰流星 / Crimson Meteor (No.1, H01)
- 毛色：深赤焰栗毛 (Rich Crimson Chestnut) — 深红栗体色，肌肉脊线带暖铜色高光
- 鬃尾：火焰铜橙渐金 (Fiery Copper-Orange → Golden tips) — 浓密飘逸，绝不可画成黑色
- 标记：额心细长流星白斑；四肢下段白章（四蹄踏雪）；蹄色深褐近黑，抛光
- 血统：英国冲刺型纯血马 (British Sprinter Thoroughbred)
- 体态：19 世纪古典赛马代表。鬐甲高耸，胸廓深窄，背腰短强，后躯半腱肌饱满，飞节角度锐利，具备顶级爆发力。整体清瘦有力，不是重型驮马。
- 跑法/气质：sprinter；擅长场地：turf
- 身份要点（参考高质量设定稿）：赤焰感来自「赤栗体色 + 铜橙鬃尾 + 肌肉暖光」，不是卡通火焰特效
